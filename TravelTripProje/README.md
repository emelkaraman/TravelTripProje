# TravelTrip

TravelTrip, **ASP.NET MVC ve .NET Framework** kullanılarak geliştirilmiş bir web projesidir. Projede blog içeriklerinin ve kullanıcı yorumlarının yönetilebildiği, admin paneli üzerinden çeşitli işlemlerin gerçekleştirilebildiği bir yapı oluşturulmuştur.

## Proje Özellikleri

* Admin giriş ve çıkış işlemleri
* Admin paneli
* Blogların listelenmesi
* Blog ekleme, silme ve güncelleme işlemleri
* Yorumların listelenmesi ve yönetilmesi
* Sayfalar arası yönlendirme
* Veritabanı işlemleri
* Partial View kullanımı
* Entity Framework ile veritabanı yönetimi

## Kullanılan Teknolojiler

* C#
* ASP.NET MVC
* .NET Framework
* Entity Framework
* Microsoft SQL Server
* HTML
* CSS
* Bootstrap
* JavaScript

##Proje Yapısı

Proje, ASP.NET MVC mimarisine uygun olarak **Model, View ve Controller** yapısı kullanılarak geliştirilmiştir.

* **Models:** Veritabanı modelleri ve Entity Framework yapıları
* **Views:** Kullanıcı arayüzleri ve Razor View'lar
* **Controllers:** Uygulama içerisindeki işlemlerin ve yönlendirmelerin yönetimi

## Veritabanı ve Güvenlik

Veritabanı bağlantı bilgileri `ConnectionStrings.config` dosyasında tutulmakta ve bu dosya `.gitignore` aracılığıyla GitHub repository'sine dahil edilmemektedir.

## Projenin Amacı

Bu proje, ASP.NET MVC ve Entity Framework kullanılarak gerçek bir web uygulamasının geliştirme sürecini deneyimlemek ve CRUD işlemleri, admin yönetimi, veritabanı işlemleri ve MVC mimarisi konularında pratik yapmak amacıyla geliştirilmiştir.
